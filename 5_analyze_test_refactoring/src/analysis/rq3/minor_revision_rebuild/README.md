# RQ3 rebuild: corrected test-smell dataset (`data_fix2`) and its outputs (`out_fix2`)

This directory rebuilds the corrected RQ3 data that the revised EMSE paper uses: 379 refactoring instances from 145 commits, at both the file level and the refactoring (method) level. The original scripts were written in a scratch directory (`.../scratchpad/rq3_recompute/`) during Claude Code session `01704e59-81d7-4c1a-b026-74183b0576b9`, and that directory was later purged. Every script here was recovered from the session transcript (main session plus subagent `a32f1031dd49cb4e9`). Each heredoc was copied verbatim, and each Python string-replacement patch was replayed exactly as it ran. Only paths were changed. The rebuild was done on 2026-10-16.

## Run

```
bash scripts/run_all.sh        # about 1-2 min; PY=<python> overrides the interpreter (default: python3)
```

Every Python call runs with `-B` and `PYTHONDONTWRITEBYTECODE=1`, so no `__pycache__` is written into the repository.

Order, as in the session:

1. `make_new_data.py` writes `data_orig` (copies) and `data_new`. `data_new` drops the 2 `Lambdarize Method` rows and merges the five try/catch/annotation/assertThrows labels into `Change Exception Verification`, leaving 403 rows and 156 commits.
2. `verify_flaws.py` writes `flags_405.pkl`, which records the annotated sides of each row.
3. `build_fixed.py` writes `data_fix` and `data_fix_mmask`. `data_fix` is the 403 rows minus the 21 one-sided pairs: 382 rows and 146 commits, with NaN kept as missing. `data_fix_mmask` also blanks every refactoring-level cell whose file-level cell is NaN on either side.
4. `build_fix2.py` writes `data_fix2`, which is `data_fix_mmask` minus the 3 rows of `openjdk/lilliput` commit 7f80683: 379 rows and 145 commits.
5. The analyses on `data_fix2` are `rq3_row_level_tables_nanmissing.py`, `new_types_effect_sizes.py`, `paragraph_after_table8.py`, `contradictory_smells.py` and `regen_change_patterns_{nanmissing,v3,v4,v6,presentonly}.py`. The paper uses `figures/change_patterns_{file,method}_n145_v6.pdf`, which are the files on Overleaf. In v6, each bar shows shares of the commits in which the smell was measured, and the label n gives that number: 145, or 63 for *Eager Test* and *Lazy Test*. The earlier v4 counted the commits in which these two smells could not be measured as *Not present*.
6. Former inline code: `table6_prevalence_fix2.py` (Table 6 and the Section 7 prevalence), `cev_grouping_fix2.py`, `eager_lazy_{nan,commits}_fix2.py` and `decompose_old_t6.py`. `letter_correction_table.py` prints the correction table of the round-2 response letter.
7. `check_paper_numbers.py` compares the results with the verified paper numbers.

## Exclusion and missing-value rules

- **Catalogue (405 to 403 rows):** `Lambdarize Method` is dropped because it is a general refactoring. The five exception-verification labels become `Change Exception Verification` (27 rows).
- **One-sided pairs (403 to 382 rows, 21 rows):** an instance is dropped when its annotation marks code on at most one side. There are 13 no-before pairs, 7 no-after pairs and 1 neither pair. Without code on both sides, its before/after smell values are not comparable.
- **Unmeasured commit (382 to 379 rows, 3 rows):** `openjdk/lilliput` 7f80683 has 3 Tuning Resources rows. tsDetect reported no smell values for its test files: every file-level smell is NaN and NumberOfMethods is 0. Its refactoring-level zeros are therefore not measurements either.
- **Missing values:** NaN is treated as missing, never as 0. The NaN cells are mainly Eager/Lazy Test, which tsDetect reports only when it can identify the production class. A pair enters a smell's statistics only if that smell is measured on both sides. Eager/Lazy Test are therefore measured in 139 instances from 63 commits. At the refactoring level, cells whose file-level counterpart is NaN are blanked (`data_fix_mmask`).
- **Table 6:** it uses the 19 tsDetect smells, excluding NumberOfMethods, Verbose Test and Dependent Test. Each measured pair × smell cell is Not Present (0 → 0), No Change (equal and > 0), Improvement or Degradation. The present-only shares drop the Not Present cells.
